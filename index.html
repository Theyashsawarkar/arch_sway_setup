Arch Linux · Wayland · Sway

Vayu

A minimal, keyboard-driven desktop, built to move as cleanly as its namesake — Vayu, the Hindu god of wind. Sway tiles and arranges windows the same way air moves: constantly, cleanly, out of your way.

What's in it

Sway

Tiling Wayland compositor (SwayFX fork — real compositor blur, rounded corners, shadows). Keyboard-first, no mouse required.

Waybar

Status bar with a fully custom Catppuccin Mocha palette — every module gets its own deliberate, distinct color.

MPD + rmpc

A real MPD daemon (zero third-party API dependency) with a richly-themed rmpc TUI client — replaced termusic entirely.

Kitty + Tmux

GPU-accelerated terminal, real glass transparency, session persistence via tmux-resurrect/continuum.

Neovim

A from-scratch, minimal Neovim config — no bloated distro, every plugin a deliberate choice.

GNU Stow

Every package here is a real, independent, symlinked stow package — reproducible, one command per tool, easy to audit.

Install

On a fresh Arch install, after archinstall finishes and you're logged into a TTY as your normal user with networking up:

bash <(curl -fsSL https://raw.githubusercontent.com/Theyashsawarkar/vayu/main/install.sh)

This installs every package, stows every config in this repo, sets up zsh/tmux/the Nerd Font the status bars need, and enables the required services. It backs up any pre-existing conflicting dotfiles first, and is safe to re-run.

Full walkthrough, manual/step-by-step installation, and how to add your own packages: see the full README on GitHub.
